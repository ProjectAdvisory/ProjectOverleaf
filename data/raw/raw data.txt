# Data Acquisition Instructions

This directory contains instructions for obtaining the raw data required to reproduce the experiments. Due to source restrictions, raw data files are not directly distributed and must be reconstructed from publicly available sources.

---

## 1. Travel Advisory Data

Travel advisory information is obtained from the U.S. Department of State official website:

* Source: https://travel.state.gov/content/travel/en/traveladvisories/traveladvisories.html

### Steps:

1. For each country listed on the website:

   * Record the **country name**
   * Extract the **advisory level** (e.g., Level 1–4)
   * Extract the associated **risk indicators** (e.g., Crime, Terrorism, Health, etc.)

2. Store the data in a structured format (e.g., CSV) with fields such as:

```text
country,advisory_level,risk_indicators
Kenya,3,"Crime; Terrorism"
France,2,"Terrorism"
India,2,"Crime"
```

---

## 2. Border (Adjacency) Data

To construct the country adjacency structure used in the graph:

### Steps:

1. Identify all countries included in the advisory dataset.
2. For each country, determine its **land-bordering neighbors** using a reliable geographic source (e.g., publicly available country border datasets or geographic references).
3. Construct a two-column table representing pairwise border relationships.

### Format:

```text
country,neighbor
India,Pakistan
India,Nepal
India,Bangladesh
France,Germany
France,Spain
```

* Each row represents a **direct land border relationship**
* The table should include all relevant country pairs present in the advisory dataset
* Relationships can be treated as **undirected** (i.e., India–Pakistan is equivalent to Pakistan–India)

---

## Notes

* Ensure consistency in country naming across datasets
* Missing or ambiguous cases should be resolved using standard country definitions
* All data is derived from publicly available sources and should be used in accordance with their respective terms of use

---

## Output Files

After processing, the following files should be placed in `data/processed/:

* `advisories.csv` — country-level advisory data
* `borders.csv` — country adjacency relationships
